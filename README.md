Number Guessing Game

About the Project

This is a simple Number Guessing Game developed using the C programming language.

Features

* Generates a random number.
* Allows users to guess the number.
* Provides feedback for incorrect guesses.
* Tracks the best score.

Language Used

* C Programming

How to Run

1. Download the main.c file.
2. Compile the program using a C compiler.
3. Run the executable file.
4. Enter a positive whole number and start guessing.
